## 🎯 Что это?

**СТРАТЕГОС** — веб-тренажёр для подготовки к экзамену по стратегическому менеджменту (НИУ ВШЭ, курс Кнатько Д.М., 12 лекций). 

**Главное:** точное воспроизведение реального экзамена ВШБ — 90 минут, 100 баллов, 4 части.
- Часть 1А: 12 одиночных вопросов (А–Д) × 2 балла
- Часть 1B: 6 множественных (A–E, all-or-nothing) × 2 балла  
- Часть 3: 8 "впиши понятие" (fuzzy-match) × 2 балла
- Часть 4: 4 открытых кейса × 12 баллов (самопроверка по эталону)

Полная симуляция + адаптивная тренировка + спейс-повторение + geymification.

### Данные о вопросах

**Структура вопроса (базовая):**
```javascript
{
  id: "q-1",        // уникальный ID
  m: "m1",          // модуль (для старой системы)
  t: "t1",          // тема (для S2)
  q: "Вопрос?",     // текст
  o: ["А", "Б", "В", "Г"],  // варианты ответа (4 штуки)
  a: 1,             // индекс правильного (0–3)
  concept: "c-oe"   // связь с концептом
}
```

**Важно:** варианты перемешиваются при каждом показе (prepQ):
```javascript
const prepQ = q => {
  const idx = shuffle([0, 1, 2, 3]);  // перемешиваем позиции
  return Object.assign({}, q, {
    o: idx.map(i => q.o[i]),          // переставляем варианты
    a: idx.indexOf(q.a)               // обновляем индекс ответа
  });
};
```
⚠️ **Ловушка памяти:** правильные ответы не всегда на "Б" (как в исходных лекциях). Перемешиваются каждый раз.

### Фабрики вопросов (s2_more_*.js)

Вопросы генерируются через фабрики для удержания консистентности:

```javascript
// Часть 1A: одиночный вопрос
const _m1 = (id, t, q, o, a, tr) => ({
  id, t, part: 1,
  q: fmt(q),            // мини-маркдаун: **жирный**, *курсив*
  o: o.map(x => fmt(x)),
  a,
  trap: tr,             // почему дистрактор привлекателен
  explain: {},          // разбор по дистракторам {0: "почему неверна А", 1: "почему неверна Б", ...}
  authors: []           // атрибуция авторов
});

// Часть 1B: множественный (all-or-nothing)
const _m2 = (id, t, q, opts, a, trap) => ({
  id, t, part: 2,
  q, o: opts,
  a,                    // массив верных индексов [0, 2]
  trap
});

// Часть 3: впиши понятие
const _m3 = (id, t, q, a, hint, c, rel) => ({
  id, t, part: 3,
  q, a,                 // массив эквивалентов для fuzzy-match
  hint, concept: c      // подсказка и концепт
});

// Часть 4: открытый кейс
const _m4 = (id, t, q, rubric, model, case_id) => ({
  id, t, part: 4,
  q, rubric,            // критерии оценки
  model,                // эталонный ответ (для сравнения)
  case_id               // ID компании
});
```

### Проверка ответов

**Часть 1–2 (множественный выбор):**
```javascript
function checkAnswer(q, userA) {
  if (Array.isArray(q.a)) {
    // Часть 2: множественный
    return setEq(userA, q.a);  // точное совпадение множеств
  } else {
    // Часть 1: одиночный
    return userA === q.a;
  }
}
```

**Часть 3 (впиши понятие):**
```javascript
function fillOk(input, accept) {
  const n = s2norm(input);  // нормализация: нижний регистр, ё→е, убрать пунктуацию
  if (!n || n.length < 2) return false;
  return accept.some(a => {
    const na = s2norm(a);
    if (n === na) return true;  // точное совпадение
    if (na.length >= 5 && (n.includes(na) || na.includes(n))) return true;  // подстрока
    return s2lev(n, na) <= Math.max(1, Math.floor(na.length * 0.2));  // Левенштейн ≤20%
  });
}
```

**Часть 4 (открытые кейсы):**
- Самопроверка по эталонному каркасу в поле `model`
- Если включена AI: callClaudeS2 → Anthropic API → получить оценку/отзыв

### Найти вопрос по ID

```javascript
const q = window.S2.DEMO.concat(window.S2.BANK).find(x => x.id === "q-123");

```

### Найти вопросы по теме
```javascript
const themedQuestions = window.S2.BANK.filter(q => q.t === "t3");
```

### Найти концепт
```javascript
const concept = window.S2.THEMES.flatMap(t => t.concepts).find(c => c.id === "c-oe");
```

### Отредактировать вопрос
1. Найти файл s2_more_pXX.js, где он определён
2. Изменить объект вопроса (текст, варианты, ответ, объяснение)
3. **Важно:** меняется только в памяти — нужно пересохранить файл
4. Браузер держит кэш → Ctrl+Shift+R (hard refresh) или закрыть вкладку/девтулс
5. Данные в localStorage не меняются автоматически — нужно Сбросить прогресс или очистить localStorage вручную

### Добавить вопрос
1. Скопировать объект похожего вопроса
2. Дать уникальный ID
3. Убедиться, что ID не повторяется (`ALL2().map(q => q.id)` в консоли)
4. Положить в нужный s2_more_pXX.js или s2_bank.js
5. В конце файла добавить в массив (например, `S2.BANK.push(вопрос)`)

## 📝 Проверка AI

Для части 4 (открытые кейсы) — AI-проверка через Claude API:

```javascript
async function callClaudeS2(prompt, model) {
  const key = S.tutor.key;  // из localStorage
  if (!key) throw new Error("Ключ Anthropic не установлен");
  
  const resp = await fetch("https://api.anthropic.com/v1/messages/create", {
    method: "POST",
    headers: {
      "x-api-key": key,
      "anthropic-version": "2023-06-01",
      "content-type": "application/json"
    },
    body: JSON.stringify({
      model: model || S.tutor.model,
      max_tokens: 1024,
      messages: [{ role: "user", content: prompt }]
    })
  });
  
  const data = await resp.json();
  return data.content[0].text;
}
```

⚠️ **Внимание:** ключ хранится в localStorage (опасно!). Используется заголовок `anthropic-dangerous-direct-browser-access`.

## ⚠️ Важные детали и ловушки

### Кэширование браузера
```javascript
// В index.html — cache-busting через версию
<script>window.__APP_VER="2026-06-15f";</script>
<script src="js/data_concepts.js?v=2026-06-15f"></script>
```

Когда меняешь код:
1. Обновить версию в index.html (меняется при каждом релизе)
2. **Локально:** `Ctrl+Shift+R` или очистить кэш браузера
3. **На Netlify:** автоматически, есть CDN-кэш (~30 сек)

### localStorage
- Ключ: `"strategos_v1"`
- Формат: один большой JSON, весь текущий прогресс
- **Риск:** если стереть, потеря всех данных
- **Тест:** `localStorage.getItem("strategos_v1")` в консоли

### Версионирование данных
Если структура S меняется (новое поле):
```javascript
S = Object.assign({}, DEFAULT_STATE, JSON.parse(...));
// Позволяет старым данным работать без миграции
```

Но если удалить поле из DEFAULT_STATE — старые данные останутся в localStorage!

### Формат часов Минцберга
- 12 часов программы = 12 тем = 12 файлов s2_more_*.js
- Каждый вопрос привязан к теме (t: "t1"–"t12")
- Темы = лекции Кнатько (в том же порядке)

### Правильные ответы перемешиваются
```javascript
// ДО prepQ: правильный ответ может быть на любой позиции
// ПОСЛЕ prepQ: правильный ответ всё ещё на индексе q.a, но варианты другого порядка
const prep = prepQ(originalQ);
prep.a;  // это индекс в массиве prep.o (перемешанных)
```

Нельзя запомнить позицию ответа!
