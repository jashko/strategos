# ⚔️ СТРАТЕГОС — боевая подготовка к экзамену по стратегическому менеджменту

Тренажёр, построенный на **реальных материалах курса** (12 лекций Кнатько Д.М., НИУ ВШЭ, 2026 + ключевые статьи: Портер, Минцберг, Ким & Моборн, Прахалад & Хамел, Джонсон/Кристенсен, Ривз и др.).

## 🎓 Экзамен ВШБ — тренажёр точного формата (главный режим)

Отдельный раздел готовит к **письменному экзамену ВШБ НИУ ВШЭ** в его реальном формате: **90 минут, 100 баллов, 4 части**.

- **Полная симуляция** (демо- и случайный вариант): 12 одиночных (А–Д) + 6 множественных (А–Е, *all-or-nothing*, количество верных не сообщается) + 8 «впиши понятие» (свободный ввод с устойчивостью к опечаткам/синонимам, проверка автора и элемента модели) + 4 открытых кейса (МТС, Аэрофлот, ВТБ×Wildberries, Wink) с самопроверкой по эталонному каркасу. Таймер, автопроверка ч.1–3, оценка по шкале 96–100→10 … 50→4.
- **Trap-drills** — «выбери более точную концепцию» на путаемых парах (ОЭ vs эмерджентная, компетенция vs ригидность, голубой океан vs провальная зона Боумена, Ур.2 vs Ур.3, CSV vs филантропия, VRIO без O vs нехватка ресурсов, CAGE-дистанции…). Главный навык экзамена.
- **Тренировка по темам** — банк вопросов с фильтром по теме/части; после ответа — разбор, **почему неверен каждый дистрактор** + атрибуция авторам.
- **Банк концепций** — 12 тем программы, по каждой концепции: определение, авторы, «ловушка» (с чем путают), мини-кейс.
- **Тепловая карта 12 тем** и список «что повторить» — на основе реальной статистики ответов (без выдуманных цифр).

Контент: демо-экзамен встроен как эталон сложности; авторский банк (часть 1/2/3) и trap-drills расширяются (минимумы промпта 96/48/72/12 добиваются итеративно).

## Запуск

```bash
cd strat
python3 -m http.server 8742
# открой http://localhost:8742
```

Или просто открой `index.html` в браузере (всё работает локально, без сборки и интернета).

## Что внутри

| Раздел | Что даёт |
|---|---|
| 🏠 **Штаб** | готовность по 12 модулям, прогноз оценки по шкале курса, слабые места, серия дней |
| 📚 **Учить** | 70 концептов с уровнями: суть → разбор → применение → критика → **ловушка на экзамене** → примеры |
| 🃏 **Карточки** | 101 карточка, интервальное повторение (SM-2) |
| 🎯 **Тест** | 172 вопроса по модулям, мгновенный разбор каждого ответа |
| 🌀 **Лабиринт** | адаптивный режим: бьёт по слабым темам, сложность подстраивается |
| 🧩 **Кейсы** | 5 комплексных кейсов (Netflix, Сбер/Яндекс, IKEA, запуск платформы, инкумбент vs ИИ) — синтез 3–5 концепций |
| 💀 **Экзамен** | симуляция: 36 вопросов, 54 минуты, оценка по шкале курса (96–100% → 10), разбор и рекомендации |
| 🤖 **AI-тренер** | чат на Claude: режимы Учитель / Сократ / Дебаты / Экзаменатор; знает курс и твои слабые места (нужен API-ключ Anthropic) |

## Структура модулей = лекции курса

1. Суть стратегии (ОЭ vs стратегия, 5P, палитра Ривза)
2. Целеполагание и стейкхолдеры (OKR/KPI/BSC/FAST, Менделоу, Shared Value)
3. Макросреда (PESTEL, VUCA/BANI, Кортни, сценарии, опционы)
4. Отраслевой анализ (5 сил, стратегические группы, КФУ)
5. RBV и VRIO (компетенции, динамические способности, бизнес-модель)
6. Цепочка ценности и синтез (WTP−SOC, TOWS, AQCD)
7. Конкурентные стратегии (Портер, Боумен, голубой океан, SAF)
8. Платформы и подрыв (сетевые эффекты, Кристенсен, амбидекстрия)
9. Корпоративная стратегия (Коуз, диверсификация, BCG, parenting)
10. Глобальная стратегия (CAGE, AAA, Бартлетт & Гошал)
11. Реализация (Румельт, Лафли–Мартин, 7S, Коттер, pre-mortem)
12. Будущее стратегии (ИИ, искажения, дебиасинг, resilience)

## Технически

Статический SPA без зависимостей: `index.html` + `css/style.css` + `js/*.js`.
Прогресс — в `localStorage` браузера. Варианты ответов перемешиваются при каждом показе.
`_sources/` — извлечённые тексты лекций (для справки, приложению не нужны).
